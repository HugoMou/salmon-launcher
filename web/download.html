01 —

Verify the download

POWERSHELL
Check SHA-256 in PowerShell 
# Installer
Get-FileHash .\SL-Setup-1.0.3-win64.exe -Algorithm SHA256

# Portable
Get-FileHash .\SL-1.0.3-portable-win64.zip -Algorithm SHA256
On SmartScreen: The installer and uninstaller are signed with a self-signed certificate (CN=SalmonLauncher, O=Hugo Mou). Machines that have not imported that certificate into their trusted root store may still see “Unknown publisher”. That is normal for self-signing and does not mean the file was altered — trust the SHA-256 instead.
02 —

Requirements

Check first

Must have

  • Windows 10 version 2004 (build 19041) or newer, or Windows 11
  • 64-bit x64 architecture only
  • Internet access on first launch for the version manifest
  • A writable %APPDATA%\SalmonLauncher folder

Not required

  • No separate .NET 10 runtime install
  • No separate Windows App SDK install
  • No existing Java needed; Temurin is fetched on demand
  • No administrator rights to install for the current user
03 —

Install steps

About two minutes
  1. Download SL-Setup-1.0.3-win64.exe and compare its SHA-256 in PowerShell.
  2. Run it. If SmartScreen appears, choose “More info → Run anyway”.
  3. Follow the wizard: pick a location and whether to create a desktop icon.
  4. Launch SalmonLauncher from the Start menu; the first run walks through basic setup.
Uninstalling keeps your data. Instances, worlds, accounts and logs all live in %APPDATA%\SalmonLauncher. The uninstaller leaves that folder alone. To wipe everything, use “Clear all data” inside the app or delete the folder manually.
Portable note: The portable build writes nothing to the registry but still uses the same %APPDATA% data folder. For a fully isolated USB setup, use it on a machine that has never run the app.
